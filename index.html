Everything you need

A full Kubernetes management experience, right in the terminal.

◉

Real-time Views

Watch pods, deployments, services and more update live. No more repeated kubectl get commands.

⌨

Powerful Shortcuts

Logs, describe, exec, port-forward, delete — all one keystroke away. Vim-style navigation.

⚙

Plugins & Customization

Extend with plugins, custom views, hotkeys and skins. Make it yours.

≡

Multi-Cluster

Switch contexts and namespaces instantly. Manage multiple clusters without leaving the tool.

⚡

Lightning Fast

Written in Go. Starts instantly and stays responsive even on large clusters.

✓

Safe by Default

Confirmation prompts for destructive actions. Read-only mode available for production.

Install in seconds

Available via most package managers.

# Homebrew (macOS / Linux)
brew install derailed/k9s/k9s
# Or with Go
go install github.com/derailed/k9s@latest
# Then just run
k9s

Also available via Snap, Chocolatey, asdf, and GitHub Releases.

Why teams love k9s

⚡

Stop typing long kubectl commands

Navigate, filter and act on resources with muscle memory. What used to take 5 commands now takes one keystroke.

See everything at a glance

CPU/memory metrics, pod status, recent events and logs — all in one place. Perfect for debugging incidents.
