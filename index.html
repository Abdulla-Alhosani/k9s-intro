k9s

Manage your Kubernetes clusters with style. A terminal-based UI that makes kubectl feel like the stone age.

Everything you need

A full-featured Kubernetes management experience, right in your terminal.

Real-time Views

Watch pods, deployments, services, and more update live. No more repeated kubectl get commands.

Powerful Shortcuts

Logs, describe, exec, port-forward, delete — all one keystroke away. Vim-style navigation.

Plugins & Customization

Extend with plugins, custom views, hotkeys, and skins. Make it yours.

Multi-Cluster

Switch contexts and namespaces instantly. Manage multiple clusters without leaving the tool.

Lightning Fast

Built in Go. Starts instantly and stays responsive even on large clusters.

Safe by Default

Confirmation prompts for destructive actions. Read-only mode available for production safety.

Install in seconds

Available via most package managers.

# Homebrew (macOS / Linux)
brew install derailed/k9s/k9s
# Or with Go
go install github.com/derailed/k9s@latest
# Then just run
k9s

Also available via Snap, Chocolatey, asdf, and pre-built binaries on GitHub Releases.
